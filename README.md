## Featured projects

### 🤖 [AI Customer Service Agent](https://github.com/matheuswilton/Atendente-IA)
A Python REST API that understands customer messages with AI, checks a store FAQ before answering, hands the conversation to a human when needed and builds SQL reports. If the AI fails, a rule-based fallback answers instead.
- **Stack:** `Python` `FastAPI` `SQL (SQLite and PostgreSQL)` `Anthropic API` `pytest` `GitHub Actions` `Docker`
- **Demo:** _(coming soon)_

### 🧾 [FiadoFácil: store credit system](https://github.com/matheuswilton/Sistema-de-Fiado)
A web system, built as a team, that helps small stores track purchases on credit, payments and customer debts, with reports, a customer ranking and a customer area. It uses locked transactions so no one goes over their credit limit, hashed passwords and CSRF protection.
- **Stack:** `PHP` `MySQL` `JavaScript` `HTML/CSS`
- **Live site:** https://fiadofacil.free.je
