## Featured projects

### 🤖 [AI Customer Service Agent](https://github.com/matheuswilton/Atendente-IA)
Understands each message with AI (intent and urgency), checks the store FAQ so it doesn't make things up, and transfers to a human when the case is urgent or unclear. If the AI fails, a rule-based fallback answers instead. Includes a chat page, a protected report dashboard and 60+ automated tests.
- **Stack:** `Python` `FastAPI` `SQL (SQLite and PostgreSQL)` `Anthropic API` `pytest` `GitHub Actions` `Docker`

### 🧾 [FiadoFácil: store credit system](https://github.com/matheuswilton/Sistema-de-Fiado)
Tracks purchases on credit, payments and debts, with reports, a customer reliability ranking and a read-only customer area. Uses locked transactions so no one goes over their credit limit, hashed passwords and CSRF protection.
- **Stack:** `PHP` `MySQL` `JavaScript` `HTML/CSS`
- **Try it:** open the [live site](https://fiadofacil.free.je) and log in with user `admin`, password `admin123`.
